Technical Assessment Question Java Tricky Operators
What is the output of the following Java expression?
int a = 5; System.out.println(a++ + ++a);
Explanation: a++ evaluates to 5 and post-increments a to 6. Next, ++a pre-increments a to 7 and evaluates to 7. Result: 5 + 7 = 12.
